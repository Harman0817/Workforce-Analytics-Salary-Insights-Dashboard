# 📊 Workforce Analytics & Salary Insights Dashboard

This project presents an interactive Tableau dashboard designed to analyze workforce composition, hiring trends, employee demographics, and salary structures.

The dataset used in this project is synthetically generated using Python, incorporating realistic distributions, constraints, and business logic to closely mimic real-world HR data.

The goal of this dashboard is to uncover actionable insights that can help organizations make informed decisions related to workforce planning, compensation, and performance management.
Workforce Analytics &amp; Salary Insights Dashboard built in Tableau to analyze employee distribution, hiring and attrition trends, and compensation patterns. This project leverages a realistically simulated HR dataset to uncover key insights and support data-driven HR decision-making.
