# 📊 Workforce Analytics & Salary Insights Dashboard

🚀 An interactive and data-driven HR analytics dashboard built using **Tableau**, designed to uncover insights into workforce distribution, hiring trends, employee demographics, and salary patterns.

---

## 🎯 Project Objective

The goal of this project is to:

* Analyze workforce composition across departments and locations
* Understand hiring and attrition trends over time
* Explore salary patterns based on education, role, and demographics
* Enable **data-driven HR decision-making**

## 🧠 Key Insights

* 📌 **Workforce Distribution**: Operations department has the highest employee count, indicating it as a major workforce driver
* 📈 **Hiring vs Attrition**: Hiring rate exceeds termination → overall workforce growth
* 🎓 **Education vs Salary**: Higher education levels (Master/PhD) strongly correlate with higher salaries
* 👥 **Demographics**: Workforce is concentrated in the 25–44 age group
* ⚖️ **Gender Distribution**: Slight male dominance across most roles
* 📍 **Location Insight**: Majority workforce concentrated in key regions (e.g., New York)

---

## 💡 Business Recommendations

* 🏢 Optimize workforce allocation in high-density departments
* ⚖️ Address gender imbalance in leadership roles
* 💰 Review compensation strategies to retain skilled employees
* 📊 Focus hiring in underrepresented regions/departments

## 🛠️ Tech Stack

* 📊 **Tableau** – Data visualization & dashboard creation

* 🎭 **Faker Library** – Synthetic data generation

## ⚙️ Methodology

### 1️⃣ Data Generation

* Created a synthetic HR dataset using Python
* Incorporated:

  * Realistic department distributions
  * Job-role based salary ranges
  * Education constraints per role
  * Age & experience logic

---

### 2️⃣ Data Processing

* Cleaned and structured data using Pandas
* Generated additional fields:

  * Age (from birthdate)
  * Salary adjustments (based on education & experience)
  * Termination logic with realistic constraints

---

### 3️⃣ Data Visualization

* Built an interactive dashboard in Tableau
* Used:

  * KPI cards for quick insights
  * Bar charts for comparisons
  * Donut charts for distributions
  * Scatter plots for correlation analysis
  * Map for geographic insights
